The pattern to break

What is different this time is worth saying plainly: the wave was honest. It took no shortcut, moved no authoritative value to buy a green, and left failing tests failing where a previous wave would have made them pass. Two of the four named failures were genuinely resolved, beat 4 reaches PROVEN on the real seed, and the cost bound went from a description to code. That is real progress.

But the second and third GO criteria are the same failure this project has now had four times: work that would make a defect visible was built, and then not wired up. Last wave the tests existed and no lane ran them. This wave the lane exists and no commit carries it. The pattern to break is not a technical one.
